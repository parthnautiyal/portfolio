Deep architectural breakdown of the 3 synchronization channels connecting the Overleaf LaTeX master copy to the portfolio data layer.

Open LaTeX Source on Overleaf
Channel 1 • Push Ingestion < 15s latency

Overleaf Git Bridge & Webhooks

Every time the resume LaTeX is modified and pushed on Overleaf's Git bridge, a Git push event triggers a Vercel Webhook that clones the latest commit and runs the deterministic AST parser.

$ git push overleaf master
→ trigger .github/workflows/sync.yml
✓ parse-resume-tex.js & deploy
Channel 2 • On-Demand Dev API Zero-Auth PIN

PIN-Gated Serverless Sync API

Developers can trigger instantaneous synchronization directly from the interactive Terminal CLI (sync --pin ****) or UI button via the secure /api/sync-resume endpoint.

$ POST /api/sync-resume
Payload: { pin: "7890", force: true }
✓ 200 OK: 5 files generated
Channel 3 • Periodic Audit Every 6 Hours

Automated GitHub Actions CRON

A scheduled GitHub Actions workflow (0 */6 * * *) polls the upstream Overleaf repository, calculates a SHA-256 hash diff, and commits updates automatically if drift is detected.

$ cron: '0 */6 * * *'
SHA-256 diff check on resume.tex
✓ Auto-commits & tags release

Deterministic AST Tokenization Pipeline & Output Artifacts

scripts/parse-resume-tex.js

The tokenizer does not perform brittle string matching. It implements a multi-stage LaTeX lexer that cleans macros, unescapes characters, extracts environments (rSubsection, resumeProjects, skillCategory), and compiles raw LaTeX into strict TypeScript modules at build time:

personal.ts
Header & Contacts
Name, title, email, phone, links
experience.ts
Work History
Roles, companies, dates, bullets
resume-projects.ts
Featured Projects
Tech stack, metrics, descriptions
skills.ts
Skills Matrix
Languages, frameworks, tools
resume.png
CoreGraphics Vector
300 DPI Retina PDF rasterizer
